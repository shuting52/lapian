# 一致性核对表

生成验证时，每个镜头逐项对比原片同位置抽帧，记 ✅ / ❌ / ➖（不适用）。

| # | 核对项 | 说明 |
|---|--------|------|
| 1 | 主体 | 主体是什么，长什么样，数量对不对 |
| 2 | 动作 | 主体在做什么，动作幅度与方向 |
| 3 | 运镜 | 运镜类型、方向、速度、起幅落幅 |
| 4 | 景别构图 | 景别、主体位置、前景/背景元素 |
| 5 | 色彩 | 主色调、饱和度倾向 |
| 6 | 光影 | 光源方向、影调（高调/低调） |
| 7 | 氛围质感 | 纪实/电影/棚拍/AI 感，噪点与锐度感觉 |
| 8 | 转场 | 与前后镜头的衔接方式 |
| 9 | 画面文字 | 有无文字、位置、出现时机 |
| 10 | 时长节奏 | 相对时长感觉（绝对时长受生成器限制，记相对） |
| 11 | 音频 | 复刻版铺的是否为原片音轨；AI 自配氛围音记 ❌ 并按 replica-generation.md 音频节修复 |
| 12 | 动作同步 | 动作节拍与 sync-map.md 时间轴对齐，误差不超过 0.5 秒 |
| 13 | 台词/旁白同步 | 内容与 transcript.md 一致，timecode 误差不超过 0.3 秒 |
| 14 | BGM/音效同步 | 卡点位置误差不超过 0.5 秒 |

## 1:1 验收门（Operating Rules 第 11 条）

交付"可复刻"前逐项过：
- 所有适用项 ✅，不适用项记 ➖ 并写明原因
- 每个 ❌ 必须有修正记录，或明确标注工具限制（如"模型不支持精确慢放，已后期实现"）
- 零未核验项：没跑过对比的维度不许写 ✅
- 达不到就继续迭代，不粉饰、不降级交付

## consistency-report.md 格式
每个镜头一段：
```
## SH01
- ✅ 主体/动作/色彩/光影/氛围
- ❌ 运镜：原片 4 次甩镜，复刻版只有 2 次 → 已修订提示词，第二次生成待跑
- ➖ 画面文字（不适用）
- 结论：部分一致，运镜待修正
```
修提示词→重新生成→更新报告，直到用户接受或生成上限用尽。如实记录，不粉饰。
