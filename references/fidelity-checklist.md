# 一致性核对表

生成验证时，每个镜头逐项对比原片同位置抽帧，记 ✅ / ❌ / ➖（不适用）。

| # | 核对项 | 说明 |
|---|--------|------|
| 1 | 主体 | 主体是什么，长什么样，数量对不对 |
| 2 | 动作 | 主体在做什么，动作幅度与方向 |
| 3 | 运镜 | 运镜类型、方向、速度、起幅落幅 |
| 4 | 景别构图 | 景别、主体位置、前景/背景元素 |
| 5 | 色彩 | 主色调、饱和度倾向 |
| 6 | 光影 | 光源方向、影调（高调/低调） |
| 7 | 氛围质感 | 纪实/电影/棚拍/AI 感，噪点与锐度感觉 |
| 8 | 转场 | 与前后镜头的衔接方式 |
| 9 | 画面文字 | 有无文字、位置、出现时机 |
| 10 | 时长节奏 | 相对时长感觉（绝对时长受生成器限制，记相对） |

## consistency-report.md 格式
每个镜头一段：
```
## SH01
- ✅ 主体/动作/色彩/光影/氛围
- ❌ 运镜：原片 4 次甩镜，复刻版只有 2 次 → 已修订提示词，第二次生成待跑
- ➖ 画面文字（不适用）
- 结论：部分一致，运镜待修正
```
修提示词→重新生成→更新报告，直到用户接受或生成上限用尽。如实记录，不粉饰。
