# AI 电商复刻模式：把一条爆款带货视频变成你的

适用：用户给 **原视频 + 产品实拍图 + 口播文案**，产出"结构 1:1、画面全换"的带货复刻视频。
前置：原片已走完拉片主流程，拿到 `shots.json` / `meta.json` / `sync-map.md` / `replica-prompts.md`。

## 输入

- `shots.json`、`meta.json`：拉片产物（镜头清单与元数据）
- `sync-map.md`：原片音画同步时间轴（字幕条样式/位置/出现时机从这里抄）
- `products/`：用户产品实拍图（jpg/png，**产品主体只许用实拍图**）
- `copy.txt`：用户口播文案，格式（二选一）：
  - 带镜头标签：每行开头加全角方括号标签再写文案（标签为 SH01 样式，前后各加一个全角括号，即 U+3010 与 U+3011）；
  - 或按镜头顺序每行一段（无标签时按序映射）。
- 可选：`keyframes/`——`extract_frames.py` 抽出的每镜关键帧，用于定构图。

## 流程（6 步）

1. **建换皮计划。** 跑 `scripts/remake_plan.py shots.json meta.json copy.txt products/ -o remake-plan.json`：
逐镜头分配 timecode、口播文案、字幕槽位、产品图引用；`swap` 字段（原主体→新主体/新背景）留空待第 3 步填写。
文案段数 ≠ 镜头数时脚本告警——先对齐文案，不动时间轴。
2. **抽帧定构图。** 沿用 `extract_frames.py` 抽每镜关键帧，人工确认"这几镜的构图就是这样"再开工生成。
不先定构图就生成 = 必返工。
3. **写重绘提示词。** 套用 `assets/remake-prompt-template.md`，每镜头一条：
- 景别/运镜/构图/光影从原片拉片结论原样搬入；
- 主体替换为用户产品 + 新场景（模特/背景/摆件按用户要求换）；
- **双 reference 声明**：①对标关键帧（定构图）②实拍产品图（定产品：logo/颜色/版式保真）；
- 产品主体**禁止**只用纯文本描述生成。
4. **生成与质检。** 逐镜头生成画面 → 抽帧与原片同位置帧并排对比：
按 `domains.md` 电商条目核对产品外观/Logo/文字不错位；走样即修提示词重生成。
AI 生成画面必须显著打标（见红线）。
5. **TTS 配音。** 口播文案逐镜转语音，文件名 `voice/SH01.wav`…：
单镜配音时长超出镜头时长时，改文案或调语速，**不许动时间轴**（Operating Rules 第 12 条）。
6. **装配与交付。** 跑 `scripts/assemble_remake.py remake-plan.json clips/ voice/ -o remake.mp4`，
再跑 `scripts/verify_remake.py remake-plan.json remake.mp4` 做机器质检，
最后人工对照 `fidelity-checklist.md` 确认后交付。

## 装配铁律

- 画面分段用 `-frames:v` 保证精确帧数；Ken Burns 后必须 scale 回目标分辨率。
- 音频：**先把配音拼成一条完整轨道，再只编码一次 AAC**；禁止分段 AAC `-c copy` 拼接（会损坏音轨）。
- 每镜音频用 `apad + atrim` 强制补齐到镜头时长，防止 amix 按最长输入提前结束。
- `drawtext` 时间条件用 `gte(n\,t)*lt(n\,t)` 写法，不用 `between`（边界帧会叠字）。
- 成片总时长与原片误差 ≤ 0.5 秒（Operating Rules 第 12 条）。

## 字幕条

样式从 `sync-map.md` 原样抄（出现时机/位置/配色），只换文字内容：
- `hook`：钩子大字（黄字 + 黑色描边，居中偏上）；
- `feature`：功能条（红底白字横条，底部）；
- `cta`：结尾行动号召（白字 + 描边）；
- `plain`：普通口播字幕（白字黑边，底部）。
字幕文字用用户文案的关键词，不抄原片字幕原文。

## 红线（Operating Rules 第 13/14/15 条）

- **产品主体是底线**：AI 图里产品 logo/颜色/款式走样即返工；能看清产品的镜头一律用实拍图做 reference 重绘，
宁可用实拍图直接合成也不 AI 瞎画。
- **换皮三件套**：只换产品、文案、背景；镜序、每镜时长、字幕条样式/位置、转场、节奏一律不动。
- **不搬运**：不直接使用原片画面、原片口播文案、原片水印/logo；"1:1"指结构复刻（镜头数/时长/转场/字幕样式对齐），
不是像素复制——接单时先说清。
- AI 生成画面显著打标（如角落"部分画面 AI 生成"），文案用用户自己的口播。
