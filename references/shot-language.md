# 镜头语言速查

拉片第 4 步填写时统一用词，避免同一概念多种说法。

## 景别
特写（脸部/物体细节）/ 近景（胸部以上）/ 中景（腰部以上）/ 全景（全身+环境）/ 远景（环境为主，人物很小）/ 大特写 / 大远景

## 机位角度
平视 / 仰视（低角度）/ 俯视（高角度）/ 鸟瞰 / 主观视角 / 过肩

## 运镜
固定机位 / 推（dolly in，写清推向谁）/ 拉（dolly out）/ 摇（pan 左右 / tilt 上下）/ 移（tracking 横向跟随）/ 跟（follow 尾随主体）/ 升降（crane up/down）/ 环绕（orbit，注明方向）/ 手持（注明晃动程度：轻微/明显）/ 变焦推拉（注明与机位移动的区别）

速度描述统一用：极慢 / 缓慢 / 匀速 / 较快 / 快速；注明起始与结束状态（如"起幅全景→落幅近景"）。

## 转场
硬切 / 叠化（注明时长感：短/长）/ 淡入 / 淡出 / 划像 / 跳切 / 匹配剪辑（动作/图形/视线匹配，注明匹配点）

## 光影与影调
顺光 / 侧光 / 逆光（剪影注明）/ 顶光 / 伦勃朗光；高调（明亮）/ 低调（暗部为主）/ 正常

## 色彩
主色调（如青橙、冷蓝、暖黄）、饱和度（高/中/低）、特殊处理（黑白、复古、赛博霓虹等）

## 音频
对白（注明人物与大意，不逐字转录除非用户要求）/ 旁白 / 配乐（情绪+配器感觉）/ 音效（注明触发画面）/ 环境声 / 静音段

## 描述示例
- 推："从云海全景缓慢推近至红日主体，3.5 秒匀速完成，落幅不停顿"
- 环绕："以古松为中心逆时针环绕约 90 度，速度匀速"
- 叠化："约 0.5 秒叠化过渡到下一镜头"
- 匹配剪辑："以仙鹤展翅的动作匹配切入云海翻涌"
- 手持："轻微手持晃动，纪实感"
