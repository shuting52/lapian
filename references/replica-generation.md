# 复刻生成（必做验证步骤）

拉片交付后，按 `replica-prompts.md` 逐镜头生成视频，验证提示词的还原度。这是交付的必要环节，不是可选项。

## 同步装配（必做）
生成只是第一步，1:1 要求按 `sync-map.md` 把六层对齐装配：
1. 画面：多镜头按顺序拼接（`ffmpeg -f concat`）；变速段按"慢放/变速段"节重定时
2. 音频：按"音频（必做）"节取段铺轨，BGM 卡点与动作节拍对齐
3. 台词/旁白：按 `transcript.md` 对轴（原声优先）
4. 核验：按 [音画同步指南](sync-guide.md) 检查同步，结论进 consistency-report.md

## 方法
1. 每个镜头一次生成调用，一条提示词只描述一个镜头，原样投喂。
2. 画幅（如 9:16）在提示词文字中声明；生成器通常固定输出时长（实测约 10 秒/条），与原镜头时长不一致是正常的——验证的是"长什么样、怎么运镜"，不是"多长"。
3. 生成后抽帧，与原片同位置帧并排对比，按[一致性核对表](fidelity-checklist.md)逐项记录。
4. 有不一致处：先修订提示词，再重新生成，直到用户接受或生成上限用尽。
5. 用 ffmpeg 拼成完整复刻版：`ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4`（list.txt 内为 `file 'a.mp4'` 逐行）。

## 音频（必做）
视频生成只出画面、AI 自配氛围音——这不等于复刻了原片音频。1:1 要求把原片音轨铺上去：
1. 从原片提取音频：`ffmpeg -i 原片 -map a:0 -c:a aac 音频.m4a`
2. 按复刻版时长适配：单镜头用 `-t` 截到原片时长；多镜头按镜头顺序取各原镜头中段（如每镜头取中部 10 秒）再 concat 拼接
3. 合成：`ffmpeg -i 复刻.mp4 -i 音频.m4a -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -shortest 输出.mp4`
4. 原片音频仅用于本片复刻验证的配音，不得用于其他用途或对外发布（见 Operating Rules 第 4 条）

## 动作/舞蹈类：分段关键帧复刻
纯文本提示词无法让模型跳出"这支"编舞——实测：模型生成的是"看着像跳舞"，编舞与原片不同。当前工具链下最接近 1:1 的方法：
1. 按舞蹈/动作段落切分（每段 2–4 秒），抽每段起始帧为锚点
2. 每段用"原片起始帧（kind:image）+ 该段动作描述"做图生视频，动作从原片姿势开始长
3. 每段取前 2–3 秒，concat 拼接；音频按同样段落从原片取段拼接，保持音画同步
4. 段间会有姿势跳变、段内动作仍是 AI 演绎——如实告知，不宣称 1:1
5. 段间跳变用 0.5s 交叉淡化（xfade）+ 音频交叉淡化（acrossfade）抹平， motion 曲线核验过渡处无尖峰

## 慢放/变速段
视频生成模型不支持精确的慢放时间指令（实测：明确写出"4–6秒慢动作"仍被忽略）。变速 beat 必须后期重定时实现，并如实告知用户：
```
# 将 4–5 秒段落做 0.5x 慢放（运动插值保证平滑），总时长保持与原片一致
ffmpeg -i 复刻.mp4 -filter_complex \
"[0:v]trim=0:4,setpts=PTS-STARTPTS[v0]; \
 [0:v]trim=4:5,setpts=PTS-STARTPTS,minterpolate=fps=60:mi_mode=mci,setpts=2*PTS[v1]; \
 [0:v]trim=5:8.3,setpts=PTS-STARTPTS[v2]; \
 [v0][v1][v2]concat=n=3:v=1:a=0[v]" -map "[v]" -c:v libx264 -crf 18 -r 30 out.mp4
```
变速位置用逐帧运动量曲线核验（慢放段帧间差异应降至约一半）。

## 数量约束
单次请求最多生成 6 条视频（含复刻验证）。镜头数超过上限时分批生成，并如实告知用户"本次生成 X 条，剩余 Y 条需下一轮"。

## 诚实边界
- 时长、节奏无法 1:1 复刻；复杂一镜到底（如多次甩镜）会被压缩简化。
- 交付时如实告知哪些对上了、哪些没对上，不夸大还原度。
