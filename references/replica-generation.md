# 复刻生成（必做验证步骤）

拉片交付后，按 `replica-prompts.md` 逐镜头生成视频，验证提示词的还原度。这是交付的必要环节，不是可选项。

## 方法
1. 每个镜头一次生成调用，一条提示词只描述一个镜头，原样投喂。
2. 画幅（如 9:16）在提示词文字中声明；生成器通常固定输出时长（实测约 10 秒/条），与原镜头时长不一致是正常的——验证的是"长什么样、怎么运镜"，不是"多长"。
3. 生成后抽帧，与原片同位置帧并排对比，按[一致性核对表](fidelity-checklist.md)逐项记录。
4. 有不一致处：先修订提示词，再重新生成，直到用户接受或生成上限用尽。
5. 用 ffmpeg 拼成完整复刻版：`ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4`（list.txt 内为 `file 'a.mp4'` 逐行）。

## 数量约束
单次请求最多生成 6 条视频（含复刻验证）。镜头数超过上限时分批生成，并如实告知用户"本次生成 X 条，剩余 Y 条需下一轮"。

## 诚实边界
- 时长、节奏无法 1:1 复刻；复杂一镜到底（如多次甩镜）会被压缩简化。
- 交付时如实告知哪些对上了、哪些没对上，不夸大还原度。
