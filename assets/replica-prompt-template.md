# 复刻提示词模板

每个镜头一条，照此结构写，可直接投喂视频生成模型。`[]` 为必填占位，`（ ）` 为填写说明。

```

画面：[主体是什么、在做什么、穿什么/长什么样，越具体越好]。
环境：[地点、陈设、景深里的次要元素]。
构图：[景别，如全景；主体在画面的位置，如居中偏右、三分法]。
运镜：[固定/推/拉/摇/移/跟/环绕，方向、速度、起幅落幅]。
光影：[光源方向、影调，如逆光剪影、低调]。
色彩：[主色调、饱和度，如青橙色调、低饱和]。
音频：[对白/旁白/配乐/音效，如"旁白男声：……"，无声注明]。
风格：[整体美术风格，如电影感写实、东方水墨]。
禁止：[不应出现的东西，如水印、现代建筑、人物变形]。
```

## 全片总览提示词（可选，用于一次性生成或统一风格）

```
全片共 N 个镜头，总时长 M 秒，画幅 16:9，[统一风格描述]。
镜头节奏：[慢/快，平均每镜头 X 秒]。
色彩与影调全片统一为：[……]。
各镜头提示词见上。
```
