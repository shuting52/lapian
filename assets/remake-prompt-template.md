# 换皮重绘提示词模板（AI 电商复刻用）

每个镜头一条，照此结构写。`[]` 为必填占位，`（ ）` 为填写说明。
与 `replica-prompt-template.md` 的区别：主体/背景是"换皮"后的新内容，
景别/运镜/构图/光影从原片拉片结论原样搬入；必须声明双 reference。

```
参考图（两张）：
ref1 = 原片本镜头关键帧（定构图：景别/角度/主体位置/运镜起落幅）
ref2 = 用户产品实拍图 products/[文件名]（定产品：logo/颜色/版式必须与实拍一致）

画面：[换皮后的主体：用户产品（以 ref2 为准，logo/颜色/文字不错位）+ 新模特/手部/场景元素，越具体越好]。
环境：[新背景/摆件（按用户要求换，原构图不变），地点、陈设、景深里的次要元素]。
构图：[从原片照搬：景别；主体在画面的位置，如居中偏右、三分法]。
运镜：[从原片照搬：固定/推/拉/摇/移/跟，方向、速度、起幅落幅]。
光影：[从原片照搬：光源方向、影调；产品高光要干净，logo 处无过曝]。
色彩：[从原片照搬主色调；产品本身颜色以 ref2 为准，不许"优化"成别的颜色]。
画幅：[9:16 或原片画幅]。时长：[本镜头时长] 秒。
风格：[整体美术风格，如电商实拍感、明亮通透]。
音频：[本镜头无声（配音后期铺）；或环境音说明]。
禁止：[水印、原品牌 logo、人物变形、产品 logo 走样、产品颜色失真、多余手指]。
```

## 填写检查（写完逐项打勾）

- [] 景别/运镜/构图/光影与原片拉片结论一致（不是"我觉得好看"的版本）
- [] ref1、ref2 两个参考图都声明了文件名
- [] 产品描述里写了"以 ref2 为准"，没用纯文本编造产品外观
- [] 禁止项里有"产品 logo 走样、产品颜色失真"
- [] 时长/画幅数字与 remake-plan.json 本镜头一致
