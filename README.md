# 视频拉片与复刻提示词 Skill

输入一条用户上传的视频，输出拉片表和逐镜头复刻提示词——按提示词重新生成，应能得到与原片镜头设计一模一样的视频。全域类型覆盖：AI 电商、影视短剧、动作模仿、舞蹈、白模视频等，不预设题材走同一套流程。

## 十一条硬规则

1. 只分析本次上传的视频；不确定的细节标 `[待确认]`，绝不编造
2. 每条复刻提示词必须自包含（画幅比/时长/运镜/主体/风格/禁止项）
3. timecode 精确到 0.1 秒，镜头首尾相接
4. 原片音画仅可用于本片复刻验证，不得他用或对外发布
5. 默认中文输出
6. **1:1 复刻是硬目标**：不许用概括代替细节
7. **提示词必须跑通生成验证**：每镜头至少生成一条，抽帧对比，未验证不得交付为"可复刻"
8. **全域类型覆盖**：不预设类型走同一套流程
9. **音画同步是复刻的一部分**：动作节拍/台词/BGM/自然音都要有时间轴并对齐
10. **类型先识别后确认**：`classify_video.py` 给建议，人工确认
11. **1:1 验收门**：所有适用项 ✅、❌ 有修正记录或标注工具限制、零未核验项，否则不交付

## 工作流程（8 步）

1. **建档** `probe_video.py` → `meta.json`（时长/分辨率/画幅/帧率/音频）
2. **抽帧** `extract_frames.py` → 场景关键帧 + 每秒 1 帧兜底
3. **切镜头与音频初检** `detect_cuts.py` → 候选切点（甩镜会误触发，需 `zone_montage.py` 10fps 联络表人工核验）；`analyze_audio.py` → 音量/静音段
4. **类型识别** `classify_video.py` → 类型建议（含证据），人工确认
5. **逐镜头拉片**：按类型跑对应粒度的逐帧拆解（舞蹈默认 10fps 联络表、节拍精确到 0.5 秒；换装加 morph 区联络表与运动曲线）；建 `sync-map.md` 六层同步时间轴；有人声则写 `transcript.md`
6. **写复刻提示词**：每镜头一条，动作节拍与变速要求从 `sync-map.md` 原样搬入
7. **自检**：`detect_black.py` 查黑场；`verify_lapian.py` 校验编号/timecode/总时长
8. **生成验证（必做）**：逐镜头生成 → 抽帧并排对比 → 按一致性核对表打分 → 按 `sync-map.md` 装配音画（原片音轨取段、变速段重定时、台词对轴）→ 同步核验 → `consistency-report.md`；不一致就修提示词重生成，直到接受或额度用尽

## 脚本一览

| 脚本 | 输入 → 输出 | 说明 |
|------|-------------|------|
| `probe_video.py` | 视频 → `meta.json` | 元数据建档 |
| `extract_frames.py` | 视频 → `frames/` | 场景关键帧 + 1fps 兜底（单镜头零切点已容错） |
| `detect_cuts.py` | 视频 → `cuts.json` | 切点候选（阈值 0.35，候选≠切点） |
| `zone_montage.py` | 视频+起止 → 联络表 jpg | 10fps 核验硬切/甩镜/morph |
| `classify_video.py` | 视频+meta/cuts/audio → 类型建议 | 启发式：切点/运动量/运动低谷/饱和度/音频 |
| `analyze_audio.py` | 视频 → `audio.json` | 音量/静音段（内容类型必须人耳确认） |
| `detect_black.py` | 视频 → `black.json` | 黑场/淡出检测 |
| `verify_lapian.py` | shots.json + meta.json | 编号连续/timecode 相接/总时长一致 |

## 实战案例

- **货轮风暴**（65.4s，3 镜头）：集装箱船/散货船/巨浪，复刻版 30s，SH02 舱盖与 SH03 巨浪还原接近
- **换装之夜**（9.3s，单镜头 morph）：6 轮迭代——伞色修正→原片音频铺轨→伞撑开动作与 3.5–4.5s 卡点对齐→4.0–6.0s 慢放后期重定时→步态专项描述；终版 9.3s 五项对齐
- **加麻加辣**（15.0s，镜前舞蹈）：转身穿帮修正→"分段关键帧复刻"（原片帧做图生视频锚点）→拼接处交叉淡化消卡顿

## 诚实边界

- 生成模型固定输出时长（约 10 秒/条），绝对时长无法 1:1
- 文本提示词无法精确控制变速 timing、复杂编舞细节——用后期重定时/分段关键帧解决，并在报告中如实标注方法
- 颗粒质感、模型自带风格倾向等多轮修正收益递减，如实告知不粉饰
- 涉及版权录音（如 BGM）不从网上代下载；仅使用用户提供的原片音轨做本片复刻验证
